# ADR-002: Adoção de Banco de Dados Time-Series para Armazenamento

| Status | Data | Responsável |
|---|---|---|
| Aceito | 2026-08-24 | Wilton (Líder da Sprint 1) |

> **Nota:** O TSDB concreto foi fixado como TimescaleDB na Sprint 2 (InfluxDB e ClickHouse rejeitados), por ser extensão do PostgreSQL com Row-Level Security por distribuidora.

## Contexto

O BOTE comprova um acúmulo massivo de 332 Terabytes em 5 anos de dados puramente temporais (telemetria contínua).

## Decisão

Utilizaremos um Time-Series Database (TSDB), otimizado para séries temporais, para suportar as consultas analíticas de tempo quase real.

## Alternativas rejeitadas

Manter bancos relacionais tradicionais (SQL) — rejeitado pois a indexação e varredura de bilhões de linhas no médio prazo degradaria totalmente a performance, inviabilizando o projeto financeiramente.

## Consequências

Ganho expressivo de performance analítica agregada. O preço a pagar é a curva de aprendizado da equipe em uma nova tecnologia.

## Governança

Alertas automatizados de APM (Application Performance Monitoring) se o tempo de resposta das consultas de leitura ultrapassar 500ms.
